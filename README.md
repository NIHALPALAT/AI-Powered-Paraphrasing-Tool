# AI-Powered Paraphrasing Tool

## Overview
Transformer-based T5 paraphrasing using Hugging Face, with grammar/spelling checks and ROUGE-based evaluation.

## Technologies
Python, Hugging Face Transformers, T5, PyTorch, NLTK, LanguageTool, ROUGE

## Project Notebook
Open the `.ipynb` file in this folder using Jupyter Notebook, JupyterLab, or Google Colab.

## Notes
- This project is based on the uploaded coursework/assignment notebook.
- Dataset files that are not included in the notebook should be added separately if you want the notebook to run locally.
